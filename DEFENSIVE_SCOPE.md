# Defensive contract

Review only caller-supplied immutable inventory/OSV snapshot bytes or explicit local ordinary JSON files. Report dated package/version-only evidence. No network service, dependency resolver, inventoried package installation/import, subprocess, exploit, remediation, source modification, archive extraction or automatic environment scan exists in the runtime.

Supported domain is PyPI names and PEP 440 ordering, explicit version enumeration and OSV ECOSYSTEM event timelines, dated withdrawal/latest-record selection and transitive alias grouping within the stated bounds. Nonmatching supported input is NO_KNOWN_MATCH in the snapshot. Current code vulnerability, actual inventory/feed completeness, provenance/authenticity and eligibility remain OPEN. Bounds and unsupported formats must never silently produce a complete PASS.

This package does not verify signatures, content hashes of inventoried distributions, exploitability, function reachability, environment qualifiers, patched local-build equivalence, an entire OSV schema, all pip-audit formats or all ecosystems. Nonsemantic descriptive metadata is ignored without dereferencing it. Caller time assertions cannot prove freshness. Live CI, actual provider decisions and human contribution require separate evidence.
